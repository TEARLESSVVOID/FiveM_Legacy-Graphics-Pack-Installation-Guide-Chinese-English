## 💡 这是什么?

**FiveM** 是 GTA V 的大型多人联机模组平台,玩法更丰富、自由度高。
而**画质包**(Graphics Pack)就像给游戏换上一副"高端眼镜":

- 🏙️ **NVE (NaturalVision Evolved)** —— 公认最真实的画质,照片级画面
- 🎬 **QuantV** —— 电影感色调,风格化拉满
- 🌈 **ReShade 预设** —— 免费的画面滤镜,新手入门首选
- ☀️ **ENB (ENBSeries)** —— 单机模式画面增强神器

> 💡 **一句话总结:** 本教程帮你把画质包 + ReShade 装进 FiveM,游戏画面焕然一新!

## ✅ 准备工作

| 需求 | 说明 |
| --- | --- |
| 🎮 **正版 GTA V** | Steam / Epic / Rockstar 平台均可,安装 **Legacy 传承版** |
| 🖥️ **显卡** | 建议 GTX 1060 及以上(低于此配置可能卡顿) |
| 💾 **磁盘空间** | 至少 30GB 空闲空间 |
| 🌐 **网络** | 稳定网络(下载画质包和游戏文件用) |

> ⚠️ **装传承版,不装增强版:** FiveM 现在同时支持两个版本,但 **Enhanced 增强版**(2026 年 7 月刚早期访问)还不稳定——画质模组用不了,社区也不成熟。本教程针对 **Legacy 传承版**(用 Rockstar Launcher 安装 *Grand Theft Auto V Legacy*)。

## 📦 步骤 1 · 安装 FiveM

> 🎯 **目标:** 桌面出现 FiveM 图标,能正常进入服务器。

1. 打开官网 [`https://fivem.net`](https://fivem.net),点击 **Download** 下载安装器。
2. 运行 `FiveM.exe`:它会自动装到 C 盘,然后让你手动选择 GTA 5 文件夹(该文件夹里要有 `GTA5.exe`)。
3. 等待首次安装完成(会自动下载一些必需文件)。
4. 启动 FiveM,登录 Rockstar 账号,进一个自己国家的服务器试试能不能玩。

✅ **完成标志:** 桌面出现 FiveM 图标,可正常进服游玩。

> 🟢 不想装画质包?现在就可以直接进游戏,本教程到此结束。

## ⬇️ 步骤 2 · 下载画质包

> 🎯 **目标:** 拿到一个**完整解压后**的画质包文件夹。

| 画质包 | 特点 | 获取方式 |
| --- | --- | --- |
| 🏙️ **NVE** | 最真实、照片级画面 | Patreon 付费支持作者(有 FiveM 专用版) |
| 🎬 **QuantV** | 电影感色调、风格化 | 官网购买 |
| 🌈 **ReShade 预设** | 免费、效果明显 | GitHub 大量免费预设 |
| ☀️ **ENB** | 单机画面增强 | [`enbdev.com`](https://enbdev.com/news.html) 免费下载 |

> ⚠️ **关键提醒:** 下载后通常得到 **zip 压缩包**,请**完整解压**!
> 千万别直接双击 zip 里的文件使用。

---

## 📂 步骤 3 · 复制文件

> 🎯 **目标:** 画质包文件成功进入 FiveM 目录。
> ⚠️ 这是**最关键**的一步,细心操作!

1. **先确认安装路径。** 画质包要装进 `FiveM.app` 文件夹:
   - 默认路径:`%localappdata%\FiveM\FiveM.app`(即 `C:\Users\用户名\AppData\Local\FiveM\FiveM.app`)
   - 自定义安装在别的位置,如 `D:\FiveM_Legacy\FiveM.app`
2. **完整解压** zip,打开解压出的文件夹,按 `Ctrl + A` 全选,再按 `Ctrl + C` 复制。
3. 打开 `FiveM.app\data`,按 `Ctrl + V` 粘贴;提示**合并/替换**就选"是"。
4. 画质包自带 `Mods`、`Plugins` 等文件夹?直接**整个拷进去**,不用自己建。
5. (可选)删除 `caches` 缓存文件夹,让游戏重新生成,避免冲突。
6. 少数画质包(如 NVE)要求放 `FiveM.app` **根目录**而不是 data,以画质包自带说明为准。

> 💡 **口诀:** 画质数据进 `data`,ReShade 全家进 `plugins`(见步骤 4)。

---

## 🎨 步骤 4 · 安装 ReShade(可选)

> 🎯 **目标:** ReShade 文件进入 `FiveM.app\plugins`。

1. 从 [`https://reshade.me`](https://reshade.me) 下载并运行 ReShade 安装器。
2. 点击 **Select game**,选 FiveM 文件夹里的 `FiveM.exe`(选 GTA V **传承版**目录里的 `GTA5.exe` 也可以,结果一样)。
3. 接口选 **DirectX 10/11/12**,勾选下载着色器(Standard effects 等)。
4. 装完后打开 `FiveM.exe` 所在目录(或你选的 GTA V 目录),把生成的这些文件**剪切**到 `FiveM.app\plugins`:
   - `dxgi.dll`、`ReShade.ini`、`ReShadePreset.ini`、`ReShade.log` 和 `reshade-shaders` 文件夹
5. 画质包自带的 ReShade 预设(`.ini`)也放进 `FiveM.app\plugins`。放其他位置也可以,但要在 ReShade 面板里选择预设,或在 `ReShade.ini` 的 `PresetPath=` 里指定路径,确保 ReShade 能找到它。

> 💡 装完的 ReShade 文件会出现在你选择的目录里,但 **FiveM 只认 `FiveM.app\plugins`** —— 必须搬进去才生效!

---

## ▶️ 步骤 5 · 游戏内启用

> 🎯 **目标:** 进服后画面发生明显变化!

1. 通过 FiveM 启动器进入任意服务器。
2. 游戏中按 **Home 键** 打开 ReShade 面板。
3. 在面板顶部下拉框里选画质包预设,勾上想要的特效。
4. 游戏设置里把**高级图形**开到超高,效果最好。

> 🟢 **完成!** 欣赏你的新世界吧!🌆

> 🔴 按 Home 没反应?检查 `dxgi.dll` 是否在 `FiveM.app\plugins`,并完成 **F8 放行**(见进阶内容)。

## 🗂️ 文件放置总结

> 安装完成后,`FiveM.app` 文件夹应该是这样的结构:

| 文件 / 文件夹 | 放到哪里 | 说明 |
| --- | --- | --- |
| 📁 画质包文件(贴图、数据等) | `FiveM.app\data` | 大多数画质包(合并/覆盖) |
| 📁 画质包自带的 Mods / Plugins 文件夹 | `FiveM.app\data` | 整个文件夹直接拷进去 |
| 📁 NVE 等特殊画质包 | `FiveM.app` 根目录 | 按画质包自带说明放置 |
| 🔧 ReShade 全家(dxgi.dll、ReShade.ini、预设 .ini、reshade-shaders、.addon) | `FiveM.app\plugins` | 全放这里 |
| 🔌 `.asi` 插件 | `FiveM.app\plugins` | 服务器可能禁用 |
| 🗂️ `.rpf`(单机) | GTA V 根目录\mods(需新建) | 联机不加载 |
| ☀️ ENB(单机模式) | GTA V 游戏根目录 | 从 enbdev.com 下载 |
| 🗑️ `caches` 缓存文件夹 | 删除(可选) | 重新生成缓存,避免冲突 |

> 🧠 **口诀:** 画质数据进 `data`,ReShade 全家进 `plugins`。

## 🧩 进阶内容

<details>
<summary><b>🛠️ ReShade 装好却没反应?(F8 放行)</b></summary>

FiveM 检测到 ReShade 后,要你在配置里**手动放行**:
1. 游戏里按 **F8** 打开 FiveM 控制台。
2. 找到 `[Addons] ReShade5=ID:xxxxxxx acknowledged ...` 那一行。
3. 打开 `%localappdata%\FiveM\FiveM.app\CitizenFX.ini`(自定义安装就在对应的 FiveM.app 里)。
4. 把控制台那行(**带你自己的 ID**)复制到文件**最底部**,`[Addons]` 段。
5. 保存并重启 FiveM。

> ⚠️ ID 每台电脑不同,别照抄示例!
</details>

<details>
<summary><b>🗂️ RPF / mods(仅单机)</b></summary>

联机时,模型、地图等 RPF 内容由**服务器**统一下发,本地 `.rpf` 文件**不会被加载**。只有单机 GTA V 用得到:在游戏根目录新建 `mods` 文件夹(或用 OpenIV → Tools → **Mods 模式**自动生成),把 `.rpf` 文件(以及需要的 `dlclist.xml` 配置)放进对应位置。
</details>

<details>
<summary><b>🔌 ASI 插件</b></summary>

新版 FiveM 自带 `plugins` 文件夹(没有就自己建)。把 `.asi` 放进去,重启 FiveM 生效。注意:服务器可能**禁用插件**,过时的插件也可能导致闪退,风险自负。
</details>

<details>
<summary><b>🎛️ ReShade Addon 扩展功能</b></summary>

从 reshade.me 下载 **ReShade with full add-on support**(未签名版;签名版不加载任何 addon)。把作者编译好的 `.addon` 文件(`.addon64` 给 64 位游戏如 FiveM,`.addon32` 给 32 位)放进 `FiveM.app\plugins`,重启游戏,`ReShade.log` 里出现 `Registered add-on` 即成功。注意:addon 版**未签名**,部分服务器可能当作弊封号,使用前先看服务器规则。
</details>

## ❓ 常见问题 FAQ

<details>
<summary><b>🎮 游戏打不开 / 闪退怎么办?</b></summary>

删除 `FiveM.app` 内的 `caches` 文件夹后重新启动;若仍不行,删除刚复制的画质包文件,逐个排除。
</details>

<details>
<summary><b>🐢 帧数太低怎么办?</b></summary>

在 ReShade 面板中减少开启的特效数量(尤其是模糊、光线类特效),或把预设强度调低。
</details>

<details>
<summary><b>⌨️ 按 Home 键没有反应?</b></summary>

确认 `dxgi.dll`、`ReShade.ini` 和预设 `.ini` 都在 `FiveM.app\plugins`,并完成上面的 **F8 放行**。
</details>

<details>
<summary><b>🚫 进服务器被踢出怎么办?</b></summary>

部分服务器禁止 ReShade / 画质包。进入此类服务器前请先在 ReShade 中点击 **Disable** 或删除 `dxgi.dll`。
</details>

<details>
<summary><b>🔍 提示 "Could not find game executable" 怎么办?</b></summary>

打开 `%localappdata%\FiveM\FiveM.app\CitizenFX.ini`,把 `IVPath=` 改成你的 GTA V **传承版**目录(如 `D:\SteamLibrary\steamapps\common\Grand Theft Auto V`),保存后重启 FiveM。
</details>

<details>
<summary><b>🤖 FiveM 支持 Enhanced 增强版吗?</b></summary>

支持,但建议用传承版:增强版 2026 年 7 月刚早期访问,不稳定、画质模组还不能用,社区也不成熟。本教程针对传承版。
</details>

<details>
<summary><b>🌐 为什么页面资源从 GitHub + CDN 加载?</b></summary>

`index.html` 是一个数据驱动的加载器:CSS、脚本、内容和图片都从 GitHub 仓库拉取,并套了 **jsdelivr CDN 备用**。GitHub 太慢(超过超时时间)或连不上时,会自动改用 CDN,任何地方打开页面都能正常显示。
</details>
