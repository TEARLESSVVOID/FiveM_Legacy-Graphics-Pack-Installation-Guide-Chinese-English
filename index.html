🎮 FiveM 画质包教程

FiveM 是 GTA V 的大型多人联机模组平台。配合画质包（如 NVE、QuantV、ReShade 预设），可以让游戏画面焕然一新，甚至接近真实照片效果。本教程将带你从零开始完成安装。

准备工作：① 正版 GTA V（Steam / Epic / Rockstar 均可）② 建议显卡 GTX 1060 及以上 ③ 至少 30GB 空闲磁盘空间 ④ 稳定的网络。

FiveM is a large multiplayer mod platform for GTA V. With a graphics pack (such as NVE, QuantV or ReShade presets), the game can look brand new — even close to real photos. This tutorial walks you through everything from scratch.

Requirements: ① A genuine copy of GTA V (Steam / Epic / Rockstar) ② Recommended GPU: GTX 1060 or better ③ At least 30GB of free disk space ④ A stable internet connection.

  1. 打开官网 https://fivem.net，点击 Download 下载安装器。
  2. 运行 FiveM.exe，安装器会自动检测 GTA V 的安装路径；如果找不到，请手动选择 GTA 5 文件夹。
  3. 等待 FiveM 完成基础安装（首次会下载一些必需文件）。
  4. 启动 FiveM，登录 Rockstar 账号，随便进入一个服务器测试能否正常游玩。
✅ 安装完成后，桌面会出现 FiveM 图标。此时可以退出游戏，进入下一步。
  1. Open https://fivem.net and click Download to get the installer.
  2. Run FiveM.exe; the installer will auto-detect your GTA V path. If not found, select the GTA 5 folder manually.
  3. Wait for FiveM to finish its base installation (it downloads required files on first run).
  4. Launch FiveM, log in with your Rockstar account, and join any server to test.
✅ A FiveM icon appears on your desktop afterwards. You may quit the game and continue to the next step.

常见画质包推荐 / 使用对比

  • NaturalVision Evolved (NVE)：业界公认最真实，需要 Patreon 付费支持作者；提供 FiveM 专用版。
  • QuantV：电影感色调，画面极具风格化。
  • 免费 ReShade 预设：GitHub 上有大量免费预设，适合新手尝试。
下载后一般得到一个 zip 压缩包。请完整解压，不要直接双击 zip 内的文件。

Recommended packs / Comparison

  • NaturalVision Evolved (NVE): widely regarded as the most realistic; supports the author via Patreon; has a FiveM-specific version.
  • QuantV: cinematic color grading with a highly stylized look.
  • Free ReShade presets: plenty of free presets on GitHub — great for beginners.
You usually get a zip archive. Extract it fully — don't run files from inside the zip.

  1. 按 Win + R，输入 %localappdata% 并回车。
  2. 进入 FiveM → FiveM.app 文件夹。
  3. 把解压后的画质包文件复制到 FiveM.app\data 文件夹（提示合并/覆盖时选择“是”）。
  4. （可选）删除 caches 缓存文件夹，让游戏重新生成缓存，可避免画质包冲突。
  5. 有些画质包（如 NVE）要求把文件放在 FiveM.app 根目录，请以画质包自带说明为准。
⚠️ 不要误删 FiveM.app 里的 GTA5.exe，它是游戏主程序；Reshade 的 dxgi.dll 也放在这个根目录。
  1. Press Win + R, type %localappdata% and press Enter.
  2. Open FiveM → FiveM.app.
  3. Copy the extracted pack files into FiveM.app\data (choose "Yes" when asked to merge/overwrite).
  4. (Optional) Delete the caches folder so the game regenerates it — this avoids conflicts.
  5. Some packs (e.g. NVE) require files in the FiveM.app root — always follow the pack's own instructions.
⚠️ Do NOT delete GTA5.exe inside FiveM.app — it's the game binary; ReShade's dxgi.dll also lives in this root folder.

  1. 从 https://reshade.me 下载并运行 ReShade 安装器。
  2. 点击 Select game，选择 FiveM.app 文件夹里的 GTA5.exe（注意不是 Steam 里的）。
  3. 图形接口选择 DirectX 10/11/12。
  4. 勾选下载着色器（Standard effects 等），等待完成。
  5. 把画质包附带的 ReShade 预设（.ini 文件）复制到 FiveM.app 根目录。
💡 安装完成后 FiveM.app 根目录会出现 dxgi.dll 和 ReShade.ini，这是正常现象。
  1. Download and run the ReShade installer from https://reshade.me.
  2. Click Select game and choose GTA5.exe inside the FiveM.app folder (not the Steam one).
  3. Select DirectX 10/11/12 as the graphics API.
  4. Tick the shaders to download (Standard effects, etc.) and wait for it to finish.
  5. Copy the pack's ReShade preset (.ini) into the FiveM.app root.
💡 After installation you will see dxgi.dll and ReShade.ini in the FiveM.app root — this is normal.

  1. 通过 FiveM 启动器进入任意服务器。
  2. 游戏中按 Home 键 打开 ReShade 面板。
  3. 在面板顶部的下拉框中选择画质包预设，勾选需要的特效。
  4. 在游戏设置中开启 高级图形设置 → 超高，效果更佳。
✅ 如果按 Home 没反应，说明 dxgi.dll 没放对位置，请回到步骤 3/4 检查。
  1. Join any server through the FiveM launcher.
  2. Press Home in-game to open the ReShade panel.
  3. Pick your pack preset in the dropdown at the top and enable the effects you want.
  4. In game settings, enable Advanced Graphics → Very High for the best look.
✅ If Home does nothing, dxgi.dll is not in the right place — check Steps 3/4 again.

游戏打不开 / 闪退怎么办？

删除 FiveM.app 内的 caches 文件夹后重新启动；若仍不行，删除刚复制的画质包文件，逐个排除。

帧数太低怎么办？

在 ReShade 面板中减少开启的特效数量（尤其是模糊、光线类特效），或把预设强度调低。

按 Home 键没有反应？

确认 dxgi.dll 位于 FiveM.app 根目录，且画质包里的 .ini 预设也在该目录。

进服务器被踢出怎么办？

部分服务器禁止 ReShade / 画质包。进入此类服务器前请先在 ReShade 中点击 Disable 或删除 dxgi.dll。

为什么这个页面的图片和视频来自 GitHub？

本页所有媒体都用 jsdelivr CDN 从 GitHub 仓库加载（形如 https://cdn.jsdelivr.net/gh/用户名/仓库@main/路径）。无论你在本地、GitHub Pages 还是任意网站打开本页，媒体都始终从 GitHub 拉取，确保显示一致。

Game crashes / won't start?

Delete the caches folder inside FiveM.app and relaunch. If it persists, remove the pack files you copied and test them one by one.

Frame rate too low?

Disable some effects in the ReShade panel (especially blur / light effects), or lower the preset intensity.

Pressing Home does nothing?

Make sure dxgi.dll is in the FiveM.app root and the pack's .ini preset is there too.

Kicked from a server?

Some servers ban ReShade / graphics packs. Click Disable in ReShade or remove dxgi.dll before joining such servers.

Why do media files load from GitHub?

All media on this page is loaded from a GitHub repo via the jsdelivr CDN (like https://cdn.jsdelivr.net/gh/user/repo@main/path). No matter where the page is opened — locally, GitHub Pages, or any website — media always comes from GitHub for a consistent result.

第 1 步：新建仓库并上传文件

  1. 在 github.com 登录后点右上角 + → New repository，仓库名随意（如 fivem-tutorial）。
  2. 进入仓库后点 Add file → Upload files，把本 index.html 和整个 assets 文件夹拖进去，提交（Commit changes）。
  3. 视频：把 fivem-gfx-tutorial.mp4 上传到 assets/video/ 文件夹（一次上传会自动创建该目录）。
📹 视频大小建议 ≤ 20MB（jsdelivr CDN 单文件限制）。更大的视频可用 mp4 压缩 工具压小，或改用 GitHub LFS / GitHub Release 托管，但链接方式会不同。

第 2 步：修改本页面的 CONFIG（文件顶部 <script>）

打开 index.html，在顶部脚本中找到 CONFIG，把 YOUR_GITHUB_USERNAME 和 YOUR_REPO_NAME 改成你的用户名和仓库名，保存并重新上传。

const CONFIG = {
  owner:  "YOUR_GITHUB_USERNAME",   // 你的 GitHub 用户名
  repo:   "YOUR_REPO_NAME",         // 你的仓库名
  branch: "main",
  video:  "assets/video/fivem-gfx-tutorial.mp4"   // 视频路径
};

第 3 步：了解媒体链接规则

图片和视频通过以下 CDN 地址从 GitHub 加载，所以无论怎么打开本页面，媒体都来自 GitHub：

https://cdn.jsdelivr.net/gh/用户名/仓库@main/图片路径.png
https://cdn.jsdelivr.net/gh/用户名/仓库@main/assets/video/视频.mp4

备用链接（GitHub 原生）：https://raw.githubusercontent.com/用户名/仓库/main/文件路径（大视频不支持拖动进度条，建议优先用 jsdelivr）。

第 4 步（可选）：开启 GitHub Pages 得到一个正式网址

  1. 仓库 Settings → Pages，Source 选择 Deploy from a branch，分支选 main，保存。
  2. 稍等 1~2 分钟，即可通过 https://用户名.github.io/仓库名/ 访问本教程，可分享给任何人。

Step 1: Create a repo and upload files

  1. Log in at github.com, click + → New repository in the top-right. Any name works (e.g. fivem-tutorial).
  2. In the repo, click Add file → Upload files, drag this index.html and the whole assets folder in, then commit.
  3. Video: upload fivem-gfx-tutorial.mp4 into assets/video/ (the folder is created automatically on first upload).
📹 Keep the video ≤ 20MB (jsdelivr CDN single-file limit). For larger videos, compress the mp4, or use GitHub LFS / GitHub Releases instead (different link format).

Step 2: Edit the CONFIG in this page (top <script>)

Open index.html, find CONFIG in the top script, replace YOUR_GITHUB_USERNAME and YOUR_REPO_NAME with your username and repo name, save and re-upload.

const CONFIG = {
  owner:  "YOUR_GITHUB_USERNAME",   // your GitHub username
  repo:   "YOUR_REPO_NAME",         // your repo name
  branch: "main",

Step 3: How the media links work

Images and video are loaded from GitHub through this CDN, so no matter how the page is opened, media always comes from GitHub:

https://cdn.jsdelivr.net/gh/user/repo@main/image-path.png
https://cdn.jsdelivr.net/gh/user/repo@main/assets/video/video.mp4

Fallback link (native GitHub): https://raw.githubusercontent.com/user/repo/main/file-path (no seeking for large videos — prefer jsdelivr).

Step 4 (optional): Enable GitHub Pages for a real URL

  1. Repo Settings → Pages, Source: Deploy from a branch, branch main, save.
